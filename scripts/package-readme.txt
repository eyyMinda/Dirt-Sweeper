Dirt Sweeper {version}
Auto sweeper and timer-minigame helper for Dirt Clicker. Unofficial fan-made tool.

1. Run DirtSweeper.exe (no install; Windows 10/11). If SmartScreen warns: More info -> Run anyway.
2. Start Dirt Clicker. Press F7 over the dig field and scroll to your collision radius level
   until the green ring matches the game's hover circle (Ctrl + scroll fine-tunes it). F7 again.
3. F5 sweeps, F8 plays the timer minigame (then click Play), F6 shows guides, F9 hides the HUD.
   The gear on the HUD opens all settings.

Settings: %LOCALAPPDATA%\DirtSweeper. To uninstall, delete the exe and that folder.
